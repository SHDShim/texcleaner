# TeXCleaner icons

These icons are the TeXCleaner application artwork previously used by the
SwiftUI version of this project. They are retained as project assets for the
cross-platform Python application.

The PNG files provide the original 16, 32, 64, 128, 256, 512, and 1024 pixel
sizes. `texcleaner.ico` is a Windows-compatible multi-resolution derivative
containing the standard 16–256 pixel icon sizes. `texcleaner.icns` is the
macOS bundle icon generated from the same artwork.
