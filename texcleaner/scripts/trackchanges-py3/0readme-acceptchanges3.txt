# What is it

Script to remove all tracking information made using trackchanges latex package.

# How to run

To accept all the changes.

python ./acceptchanges3.py -c -n --infile="/Users/danshim/Library/CloudStorage/Dropbox-ASU/Sang-Heon Shim/Apps/Overleaf-1/Mg2FeH6 paper v1/0-main.tex" --outfile="/Users/danshim/Library/CloudStorage/Dropbox-ASU/Sang-Heon Shim/Apps/Overleaf-1/Mg2FeH6 paper v1/0-main-NoTrack.tex"
